# NoteCLI - 命令行笔记管理器

NoteCLI 是一个基于 Spectre.Console 的命令行笔记管理器，提供完整的笔记管理功能。

## 功能特性

- ✅ **主菜单**：使用 SelectionPrompt 提供直观的菜单选择
- ✅ **笔记列表**：用 Table 展示笔记，支持按分类和标签过滤
- ✅ **新增笔记**：使用 TextPrompt/SelectionPrompt/MultiSelectionPrompt 输入笔记信息
- ✅ **编辑/删除**：编辑现有笔记或删除不需要的笔记
- ✅ **搜索功能**：按关键词与标签组合搜索，用 Markup 高亮匹配内容
- ✅ **导出功能**：选择导出为 Markdown 或 JSON 格式，显示导出进度
- ✅ **帮助页面**：用 Panel/Rule/Markup 展示使用说明与示例
- ✅ **退出确认**：退出时显示 Yes/No 确认

## 技术栈

- C# .NET 6+
- Spectre.Console - 命令行UI库
- System.Text.Json - 本地JSON存储

## 运行方法

### 方法一：直接运行

1. 确保已安装 .NET 6+ SDK
2. 进入 NoteCLI 目录
3. 执行命令：`dotnet run`

### 方法二：编译后运行

1. 进入 NoteCLI 目录
2. 执行命令：`dotnet build`
3. 运行编译后的程序：`dotnet run --project NoteCLI`

## 使用说明

### 主菜单选项

1. **笔记列表**：查看所有笔记，支持按分类和标签过滤
2. **新增笔记**：创建新笔记，输入标题、内容、分类和标签
3. **编辑/删除**：选择现有笔记进行编辑或删除
4. **搜索**：按关键词和标签搜索笔记
5. **导出**：将所有笔记导出为 Markdown 或 JSON 格式
6. **帮助**：查看使用说明
7. **退出**：退出程序

### 操作快捷键

- 使用上下箭头键选择菜单选项
- 按 Enter 键确认选择
- 按任意键返回主菜单

### 数据存储

笔记数据默认存储在用户目录下的 `notes.json` 文件中，格式如下：

```json
[
  {
    "Id": "guid",
    "Title": "笔记标题",
    "Content": "笔记内容",
    "Category": "分类",
    "Tags": ["标签1", "标签2"],
    "CreatedAt": "创建时间",
    "UpdatedAt": "更新时间"
  }
]
```
